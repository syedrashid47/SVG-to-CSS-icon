SVG to CSS icon sheet

Drop in a batch of SVG files and get one stylesheet. Each file becomes a class you can put on any element. Visio, Figma and downloaded SVGs are cleaned up on the way in.

The file name is added after this. .icon-name

Any CSS length, for example 1em, 24px or 1.5rem.
